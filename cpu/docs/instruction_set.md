## 指令格式

### R型指令格式 (32位)
```
[31:25] [24:20] [19:15] [14:12] [11:7] [6:0]
funct7   rs2     rs1    funct3   rd   opcode
```

### I型指令格式 (32位)
```
[31:20]    [19:15] [14:12] [11:7] [6:0]
imm[11:0]   rs1    funct3   rd   opcode
```

### U型指令格式 (32位)
```
[31:12]      [11:7] [6:0]
imm[31:12]    rd   opcode
```

### S型指令格式 (32位)
```
[31:25]    [24:20] [19:15] [14:12] [11:7]    [6:0]
imm[11:5]   rs2     rs1    funct3  imm[4:0] opcode
```

### B型指令格式 (32位)
```
[31] [30:25] [24:20] [19:15] [14:12] [11:8] [7] [6:0]
imm[12] imm[10:5] rs2 rs1 funct3 imm[4:1] imm[11] opcode
```

### J型指令格式 (32位)
```
[31] [30:21] [20] [19:12] [11:7] [6:0]
imm[20] imm[10:1] imm[11] imm[19:12] rd opcode
```

## 五级流水线架构

1. **IF (Instruction Fetch)**: 从指令存储器取指令
2. **ID (Instruction Decode)**: 指令译码，寄存器读取，立即数生成
3. **EX (Execute)**: ALU运算，分支条件判断，地址计算
4. **MEM (Memory Access)**: 数据存储器访问
5. **WB (Write Back)**: 结果写回寄存器文件

## 流水线寄存器

- **IF/ID**: PC+4, 指令
- **ID/EX**: PC+4, 寄存器数据, 立即数, 寄存器地址, 控制信号
- **EX/MEM**: PC+4, ALU结果, 写数据, 寄存器地址, 控制信号
- **MEM/WB**: ALU结果, 内存数据, 寄存器地址, 控制信号
